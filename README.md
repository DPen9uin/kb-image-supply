# kb-image-supply 知识库配图补给 Skill

> 一个简单的为 AstrBot 知识库检索结果自动配图的skill —— 纯文本RAG功能扩展    ——by 青色照明 团队 面向师生双端的教学智能体方案

## 注意

**这个skill并未配备文件读取脚本**

## 功能简介

AstrBot 执行知识库检索（`astr_kb_search`）后，本 skill 结合检索结果与对话语义**主动判断是否需要配图**；需要时，在本地 `/AstrBot/data/kb_assets/` 下查找与知识库文档同名的源文件（PDF / PPTX / DOCX），定位检索内容在文件中的位置并提取对应图片，**发送给用户后立即删除临时文件**。

## 触发场景

触发本 skill 的典型请求：

- 用户要求出题、讲解图文内容、看示意图 / 显微照片 / 结构图 / 图表
- 检索结果含图注文字
- 知识库文档中的图是本轮对话的核心内容

## 工作原理

```
知识库检索（astr_kb_search）
        │
        ▼
根据检索结果 + 对话语义判断是否需要配图
        │（需要）
        ▼
在 ./kb_assets/<知识库名>/ 下定位同名源文件
        │
        ▼
在源文件中搜索关键词定位目标图（注意教材页码与 PDF 页码的偏移）
        │（PDF/PPTX 用渲染裁剪，DOCX 解压 word/media/）
        ▼
提取图片 → 保存到临时目录（如 /tmp/kb_img_*/）
        │
        ▼
随回复正文一起发送图片 → 发送后立即删除临时文件
```

支持三种源文件格式：

| 格式 | 提取方式 |
|------|----------|
| PDF | `pymupdf` 定位页码，裁剪渲染目标区域 |
| PPTX / DOCX | 解压 zip，从 `ppt/media/` / `word/media/` 提取对应图片 |

## 使用说明

0. **使用前**：请在astrbot的data目录下新建**kb_assets**目录
1. **静默执行**：找图过程（定位源文件、搜索、渲染、保存临时文件）不向用户播报，图片直接附在当轮回复结果中；仅当失败且需要用户配合（源文件缺失、定位不到图、图片与内容不符）时才说明情况。
2. **临时文件即时清理**：图片发送后立即删除临时目录，绝不写入 `/AstrBot/data/kb_assets/`。
3. **页码偏移**：教材印刷页码 ≠ PDF 页码（封面、目录、页眉等会导致偏移），定位时必须校验，例如「教材第45页→PDF第47页」。
4. **同名源文件**：优先使用与知识库文档**同名**的源文件，避免跨文档取错图（如误用必修1 的图回答必修2 的内容）。
5. **单图优先**：同一内容有多张候选图时，取与检索内容最贴合的一张发送，其余不发送（用户要求全部除外）。

## 使用示例

用户提问：「讲讲氨基酸是怎么形成血红蛋白的？」

- 检索知识库 → 命中必修1「氨基酸形成血红蛋白」相关段落
- 判断：该内容教材配有示意图 → 需要配图
- 定位 `./kb_assets/高中生物/高中生物 必修1.pdf`，搜索「血红蛋白」定位页码
- 提取图中「血红蛋白分子结构示意图」→ 发送 → 删除临时文件
- 回复正文中说明图片出处与内容要点
